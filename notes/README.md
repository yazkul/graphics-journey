# 笔记说明

## 为什么按「讲次」分文件

一开始我按主题分（"图形学管线""光栅化"），写起来就乱了——因为**一节课往往横跨好几个主题，一个主题又横跨好几节课**。
现在改成：**一讲一个文件，严格跟着视频顺序走**。看到哪讲到哪，笔记就是那一讲的样子。

## 目录

```
notes/
├── README.md          ← 本文件
├── lectures/          ← 22 讲，一讲一个文件
├── 报错记录.md         ← 环境/代码踩的坑
└── 周报/               ← 每周复盘
```

## 每个文件里的 6 个小节怎么用

| 小节 | 什么时候写 | 作用 |
|---|---|---|
| 0. 一句话：解决什么问题 | **看完立刻写** | 写不出来 = 没懂 |
| 1. 关键概念 | 边看边记 | 3~5 条就够，别抄 PPT |
| 2. 核心公式 | 边看边记 | 公式要能手推，不是抄下来 |
| 3. 我自己推了一遍 | **合上视频之后** | 这一步最值钱，卡在哪写哪 |
| 4. 和作业的关系 | 写作业前回头看 | 知道学它干嘛 |
| 5. 没懂的 ??? | 随时 | 别当场死磕，记下来周日清 |
| 6. 一句话总结 | 看完写 | 能讲给外行听 = 真懂 |

## 三条规矩

1. **先看视频，后写笔记**。不要边看边逐字抄，那是打字机不是学习。
2. **不懂就打 `???` 继续往下**。图形学的概念是"后面解释前面"的，卡在第 3 讲会寸步难行。
3. **每周日清账**：把这一周所有 `???` 翻一遍，能自己讲通就删掉，讲不通就去搜/问。
